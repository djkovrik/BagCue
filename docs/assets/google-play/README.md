# Google Play artwork

- `app-icon-512.png`: 512 × 512, exported directly from the approved production icon to preserve exact brand geometry.
- `feature-graphic-1024x500.png`: 1024 × 500, generated using the built-in OpenAI image generation tool with the production icon as identity reference, then resized and encoded as opaque RGB PNG.
- `feature-graphic-source.png`: retained original generated image (exec-bbe09ce4-6820-4f78-90e8-58cf1c391276.png).
- `generation-prompt.txt`: exact generation prompt.
- `exports.json`: verified dimensions, file sizes and alpha metadata.

Both deliverables are below the user-specified 1 MB / 15 MB limits. Only the brand name is embedded, so the feature graphic can be shared by EN and RU listings. Original project artwork; no third-party artwork incorporated. These assets were prepared locally, not uploaded to Google Play.
